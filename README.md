## 🌐 Overview

<table>
<tr>
<td width="60%">

A **premium futuristic dark-themed class timetable website** built for the **CSE 2nd Semester students** of Government Polytechnic, Adityapur. Designed to feel like a professional portfolio rather than a boring schedule page.

The site replaces the paper timetable entirely — it's always up-to-date, highlights your **current class in real time**, and includes the **complete NEP-2020 syllabus** for every subject, all wrapped in a stunning neon glassmorphism UI.

> Built entirely with **pure HTML · CSS · JavaScript** — no frameworks, no build tools, no backend. Works instantly on GitHub Pages.

## 🚀 Deployment

```bash
# 1. Clone this repository
git clone https://github.com/Parthsharma321/CSE-Time-Table-2nd-Semester.git

# 2. Go into the folder
cd CSE-Time-Table-2nd-Semester

# 3. Push changes (if any)
git add .

git push origin main
```

Then go to: **Repository → Settings → Pages → Source: `main` branch, root `/`** → Save

Your site will be live at:
```
https://parthsharma321.github.io/CSE-Time-Table-2nd-Semester/
```

```bash
# Option A: Python server
python -m http.server 8000
# Visit: http://localhost:8000

# Option B: VS Code Live Server
# Install "Live Server" extension → Right click index.html → "Open with Live Server"

# Option C: Just open directly
start index.html   # Windows
open index.html    # macOS
```

> ⚠️ No `npm install`, no build step, no dependencies — it's all vanilla HTML/CSS/JS.

## 🛠️ How to Edit

### ➤ Update the Timetable

Edit the `SCHEDULE` object in **`script.js`**:

```js
// script.js
const SCHEDULE = {
  1: [ // Monday (1=Mon, 2=Tue, ... 6=Sat)
    { name: 'S&A', teacher: 'MRG', startH: 10, endH: 11 },
    { name: 'FEEE', teacher: 'SK', startH: 11, endH: 12 },
    // Add or change classes here ↑
  ],
  // ... other days
};
```

### ➤ Add a New Announcement

Edit the `ANNOUNCEMENTS` array in **`script.js`**, or add one live from the browser console:

```js
// script.js – static addition
const ANNOUNCEMENTS = [
  {
    type:  'Exam',             // Label text
    color: 'var(--neon-pink)', // Badge colour
    title: '📝 Mid-Sem Exam',  // Card heading
    body:  'Sessional exams scheduled for June 2026. Check noticeboard.', 
    date:  'June 2026',        // Footer date
  },
  // ... existing entries
];

// OR from browser DevTools console (no file edit needed):
addAnnouncement({ type: 'Notice', color: 'red', title: '🚨 Holiday', body: 'College closed tomorrow.', date: 'Today' });
```

// syllabus.js
const SYLLABUS_DATA = [
